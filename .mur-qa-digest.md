

# UNIT: agent-domain — agent lifecycle
SUMMARY: The `mur agent` CLI subtree is functional and robust: create (with --no-interactive), list (+--json), status, send (A2A), card, inspect, install-service (--dry-run), stop, export, and remove --purge all worked, and cleanup left no orphaned processes or residual files/symlinks. The main problems are in the mur-agent-manage SKILL.md, which is out of sync with the CLI: it documents `mur agent export <name>` without the now-mandatory `--out` flag (the documented command fails), and it tells users to "follow the wizard" on create when create is non-interactive by default. Lesser issues: an LLM failure during `send` is reported as a "completed" task rather than failed, and `mur-agent-runtime --help` prints an error+usage but exits 0.
